    A REPOSITORY, IN RINGS

    每一次共建，都有迹可循。

    把 self-llm 的真实 Git 历史铺成年轮。按提交时间从内向外生长，每条记录都有自己的位置，也有写下它的人。

    01立方柱是提交每根细长立方柱对应一次提交。颜色表示主要改动区域，柱高随改动文件数增加；接近俯视时收平并放大为带亮边、暗边和柔和投影的小方块，斜视时恢复立体高度。点击可查看提交详情。
    02环带是季度立方柱依次旋转约 137.508°，半径随提交序号的平方根增长，形成向日葵种子般的螺旋，保留清晰的侧面、柱高与投影。细环标记季度，空间距离不表示日期间隔。
    03头像是作者标记跟随最近活跃的贡献者；左侧按当前时间之前的累计提交次数动态排序。点击某人可追踪其提交，滚动可查看全部。
    04时间可以倒流拖动时间轴跳转；空格播放 / 暂停，方向键逐条浏览，⌘ / Ctrl K 查找提交。沿圆周拖动拨转圆盘；在盘心上下拖动或按住 Shift 拖动调整倾角。

    贡献者按 GitHub 返回的作者账号 ID 归组，同一账号的不同邮箱合并计数，显示 GitHub 用户名。未关联账号的记录保留 Git 署名，并标注 Git；邮箱未嵌入此文件。头像已内嵌，缺失时使用姓名缩写。榜单只统计当前时间之前的提交，含合并提交；次数相同时按首次贡献顺序排列。合并提交保留为立方柱，文件变更仅统计非合并提交；重命名按删除与新增展示。历史文件数按累计出现过的路径去重，包含后来删除的文件。

    灵感来自 The Growth Rings of SGLang Omni ↗。本页使用 Canvas 绘制可交互的 2.5D 年轮，数据、样式和头像都在这个 HTML 中；离线可播放，GitHub 链接需联网。
