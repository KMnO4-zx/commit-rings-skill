# 已确认的视觉与交互

默认从 `assets/history.template.html` 生成。只有用户要求更改设计时才调整模板；普通换仓库只替换数据和品牌信息。

## 年轮

- 暖纸色背景、衬线大标题和日期，中央年轮，左侧贡献者榜，右侧提交详情，底部时间轴。
- 每条 commit 一个柱子，包括 merge。按 Git 提交者时间排序，由内向外生长，时间轴压缩没有提交的日子。
- Vogel 黄金角排列：`angle = n × π(3−√5) − 0.25`，`radius = 6.9 × √(n+6)`。增加 6 留出盘心。相邻步旋转约 137.508°，平方根半径保持近似等面积分布。
- 细环标记季度；空间距离不代表真实日期间隔。
- 斜视为细长立方柱：宽 4.4，柱高 `12 + min(18, log2(1+变更路径数)×3)`，保留顶面、两侧明暗和投影。
- 接近俯视（投影比例 0.82→0.97）时平滑收平，并把边长放大至原来的 1.65 倍。完全俯视是正方形；描边、顶部渐变、亮暗边及柔和阴影提供层次。不能重新变成扇环或纯色小点。
- 默认源码绿、文档黄、测试浅绿、配置橙、资源橘红、维护深绿。颜色是分类，不是贡献次数或质量。用户可要求针对领域重新分类，规则与图例要同步。
- Hover 与 selected 按各自底色提亮整个柱子，保持色相和侧面明暗；禁止所有类别统一改黄。

## 手势

- 圆周拖拽根据鼠标相对盘心的极角增量旋转，按当前倾角将屏幕 Y 还原。上缘和下缘的同向水平拖动对应相反角度，才能让抓住的位置跟随指针。
- 用 `atan2(sin(Δ), cos(Δ))` 处理 ±π 边界。经过盘心时暂停角度追踪、离开后重新锚定，避免跳转。
- 起点落在中央约 22% 半径内时，上下拖动调整倾角；向上拉趋近俯视。按住 Shift 可在任意起点调整倾角。
- 滚轮缩放；实际拖动超过 5 px 才取消点击；pointer capture 支持拖出画布后释放。抓住圆盘时停止自动旋转。
- 重置回到默认斜视。不要恢复旧的 `yaw += dx` 手感。

## 作者与时间

- 左侧显示头像、GitHub login（未匹配则显示 Git 署名并加 Git 标记）和累计次数。
- 计数只包含当前时间轴位置之前的提交，倒放时扣除；按次数降序，平手按首次出现顺序。条目以 CSS 位移动画重排，完整榜单可滚动。
- 点击作者追踪该人的提交；圆盘头像标记最近活跃作者与当前选中提交。
- 播放、倍速、逐条前后、搜索、详情与全屏都应保留；键盘空格播放，方向键逐条，⌘/Ctrl K 搜索。

`examples/self-llm-history.html` 是原始项目的定制示例，采用模型教程/硬件等专属类别。通用模板使用自己的路径分类，不能沿用 self-llm 的专属文案和统计数据。
